# 诗画长卷 · Shihua Scrolls

以水墨动态长卷呈现中国古典诗词的「以景寄情」与含蓄之美。
Classical Chinese poetry as living ink-painting scrolls.

| 卷 | 目录 | 内容 |

| 边塞诗歌集 | `biansai/` | 大漠孤烟、四卷十八首边塞诗 |
| 江南水乡诗歌集 | `jiangnan/` | 烟雨水巷、四卷十六首江南诗 |

打开根目录 `index.html` 或各子目录的 `index.html` 即可浏览（纯静态，无需构建）。

诗文据《全唐诗》《全宋词》《乐府诗集》《诗经》等通行本，个别字有异文；画作为 AI 生成的意象画。
